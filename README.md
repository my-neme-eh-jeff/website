Aman Nambisan's portfolio and blog, at
[amannambisan.com](https://amannambisan.com).

## What's in it

- **A terminal for a home page.** Query projects, posts and roles
  kubectl-style with `k get projects`, grab the `resume`, or switch between
  seven palettes with `theme`. Keys click, and Android phones buzz.
- **Ask it anything about Aman.** Anything that isn't a command goes to Gemma 4
  26B-A4B, running in Ollama on the PC on his desk, reached through a
  Cloudflare Tunnel. It streams the answer and suggests three questions to ask
  next. When the desk is off or busy, a model on Poe answers instead.
- **An ASCII desk that lights up.** The desk on the home page is plain text,
  relit cell by cell with WebGL2. The lamp's arm is on springs and follows your
  mouse, or your caret while you type. Point it at the PC and the case turns
  see-through: an RTX 2060 and a Ryzen 5 5600X, the parts answering the chat.
- **The model was chosen by evals, not by eye.** Six open models were tested
  against the old one, graded by judges from several AI companies, with every
  run committed. [Results below](#evals).
- **Link previews drawn by code.** The share card and video are generated by
  scripts, the video recorded from the built site.
- **Built with [Qwik 2](https://next.qwik.dev).** Every page is prerendered to
  static HTML and resumes instead of hydrating, so the text is there before any
  JavaScript runs.
- **$0 to host.** Cloudflare serves the pages as free static assets; a single
  Worker handles only the chat.
- **Checked on every build.** `pnpm run verify` tests the real output: WCAG AA
  contrast in every palette, a per-page CSP, WebP-only images, exact-pinned
  dependencies.

## Evals

The chat is tested the way visitors meet it: the runner uses the site's own
prompt and relay code, asks every test question, and grades the answers with
code checks and a panel of judge models. No judge grades a model from its own
maker. Prompts are tuned on one set of wordings and checked on held-out ones.

Runs execute on the desk (`pnpm run eval`), and `pnpm run eval --publish <run>`
commits a run to [`evals/results/runs/`](evals/results/runs/), raw answers and
judge votes included.

**Choosing the desk model.** Six open models that fit on the desk ran against
gpt-oss-20b, the model it served at the time, on 117 questions. The two best
then answered all 184 wordings three times each.

| Model                     | Bake-off: accurate / all right | Final round: accurate / all right | First word |
| ------------------------- | ------------------------------ | --------------------------------- | ---------- |
| gpt-oss-20b (previous)    | 82% / 65%                      | —                                 | 1.8s       |
| Qwen3.6-35B-A3B           | 96% / 62%                      | 88% / 52%                         | 2.0s       |
| **Gemma 4 26B-A4B** (now) | 91% / 89%                      | 86% / **84%**                     | **0.8s**   |

_Accurate_ means right on facts and behaviour. _All right_ also requires the
formatting and the three suggested questions to be right. Accuracy was a
statistical tie, so the rule written before grading picked Gemma on answers
fully right.

More in [`evals/README.md`](evals/README.md) and the write-ups:
[prompt rules](evals/results/2026-10-19-prompt-rules.md),
[the bake-off](evals/results/2026-10-20-desk-model-bake-off.md),
[the final round](evals/results/2026-10-22-desk-model-finalists.md).

## Getting started

Needs Node 24 and pnpm.

```sh
pnpm install --frozen-lockfile
pnpm start           # dev server
pnpm run build       # client + SSG + type check + lint
pnpm run verify      # check the build's invariants against dist/
pnpm run preview     # serve the built output
```

Every push to `main` deploys through Cloudflare Workers Builds.
